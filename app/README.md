# Urban Strike

Mobile tactical shooter prototype built with native Android Canvas/Java. The project is dependency-free and uses fictional enemy factions.

## Included
- Landscape mobile controls with virtual joystick + fire button.
- Urban map with 20 buildings (10 in each fictional enemy sector).
- 5 sidearms, 6 rifles, 3 grenade/launcher slots and 3 machine guns.
- Enemy AI, health bars, score, sector-complete state.
- GitHub Actions workflow that compiles `app-debug.apk` and publishes it as a workflow artifact.

## Build
Use Android Studio/Gradle with Android SDK API 37 and JDK 17. CI uses Gradle 9.6.1 and Java 17.
